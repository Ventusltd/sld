# SLD library working rules

This repository owns its source catalogue, fetched open assets, drawing-library
API, education guide, and bounded local GPU receipts. UK/IEC conventions and metric
units are intended defaults; do not claim conformity from a symbol's appearance.

Keep source URL, immutable revision, original licence, attribution and SHA-256.
Reference-only material stays as links. Do not fetch confidential project material
or include private names, coordinates, drawings, contracts or inspection images.
Do not execute downloaded model files as code during acquisition.

Electrical terminals, graphical anchors and geometric overlaps are different
concepts. Preserve them separately. Draft drawings must not acquire approved status
from a browser test or a GPU agreement receipt. Production symbols require reviewed
approved project drawing evidence dated after 2012; missing evidence stays explicit.

Reuse the paired raw-CUDA/CuPy furnace pattern. Report unique cases, repeated
executions, threshold cases, timings and mismatches separately. Keep outputs bounded
and retain the last successful publication if acquisition or any gate fails.

Never enable untrusted pull-request execution on a local GPU runner. Do not change
security software settings. Use existing workflows for hosted browser verification.
